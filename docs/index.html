Can wastewater signal a hospital surge before it happens?

We built a next-week COVID-19 surge classifier using community wastewater signals, recent hospital admissions, and seasonal patterns — then evaluated where it works, where it fails, and who the data may leave out.

Research question

Can rising SARS-CoV-2 concentrations in wastewater predict a COVID-19 hospital-admission surge in the following week?

Surge: next-week admissions rise by more than 10% and exceed that state's median admissions level.

01 · Approach

From a community signal to an early warning

Wastewater surveillance captures viral activity without depending on individual testing. We transform that signal into state-week features and ask the model to classify what happens one week later.

  1. 01
    ✦

    Virus enters wastewater

    Community shedding creates a population-level signal in sewer systems.

  2. 02
    ◒

    Operators collect samples

    Treatment plants report samples with site, date, concentration, and coverage information.

  3. 03
    ⌁

    Labs quantify viral RNA

    We clean and normalize measurements, then align them to CDC Saturday-ending epiweeks.

  4. 04
    ↗

    Model predicts next week

    XGBoost combines wastewater, recent admissions, lags, seasonality, and data-quality signals.

02 · Data + features

Two CDC datasets, one carefully aligned timeline

The cleaning work mattered as much as the model. Unit mismatches, non-detects, duplicate measurements, and a one-day week alignment bug could all create false signals.

01

CDC Wastewater

SARS-CoV-2 wastewater surveillance

Started with 584,287 samples. We retained comparable liquid-wastewater units, handled non-detects, log-transformed the signal, aggregated by state-week, and required at least two reporting sites.

02

CDC NHSN

Weekly hospital respiratory metrics

We removed aggregate region rows, missing admission counts, and the May-Oct 2024 voluntary-reporting window so paperwork changes would not masquerade as a real drop in disease.

Keep units comparable

About 100K dry-sludge measurements were removed; they are a different physical quantity from copies/L wastewater.

Handle non-detects

40,336 reported zeros meant “below detection,” not “no virus.” They were replaced with LOD/2 and flagged.

Align epiweeks

Wastewater initially ended on Sunday; NHSN ends on Saturday. That one-day mismatch made the first join return zero rows.

σ

Normalize locally

conc_site_z_mean asks whether a reading is unusual for its own sites rather than comparing raw lab values across systems.

03 · Model evaluation

96% accuracy can still mean “catch zero surges.”

Only 88 of 2,269 held-out state-weeks were true surges (3.9%). That makes accuracy a dangerous headline metric, so we compared precision, recall, F1, balanced accuracy, ROC-AUC, and PR-AUC.

Why accuracy misleads 96.1%

accuracy from doing nothing

A model that predicts “no surge” every week reaches 96.1% accuracy and catches 0 of 88 real surges.

PR-AUC is more honest here. The no-skill floor is 0.039; XGBoost reaches 0.299.

“Unusual for this site” beats “large raw number.”

conc_site_z_mean ranks 2nd while raw log10_conc_mean ranks 4th. Site-level normalization reduces cross-plant measurement bias and became a core model signal.

02

The model reads movement across time.

Lagged wastewater features fan out through the ranking. The model is combining recent history rather than relying on one week's measurement.

!

Important data-quality caveat

The project later identified a denominator mismatch in admits_per100k: statewide admissions were divided by wastewater-plant population. Because that feature ranks first in SHAP, fixing it is a top future-work priority.

05 · Responsible AI

A useful warning system can still amplify blind spots.

Model performance is inseparable from who appears in the surveillance infrastructure. Coverage, reporting rules, label choices, and class imbalance all shape what the model learns.

Where bias can amplify

Missing communities can become missing warnings.

About 20% of U.S. households are not connected to monitored sewer systems. A model trained on well-covered locations can under-warn communities that are already less visible in the data, including some rural and lower-income areas.

Where the process can mitigate bias

Make artifacts visible — and design around them.

We normalized wastewater against each site's baseline, removed the voluntary-reporting window, split train/test by time, separated future-derived targets from model inputs, and report metrics beyond accuracy.

01

Geographic representation

Septic and unmonitored communities are absent, not merely noisier.

02

Missing history

Early state-weeks lack lag values; models handle missingness differently.

03

Class imbalance

Surges are only 3.9% of the test set, making accuracy deceptive.

04

Label choice

“Surge” is one operational definition; a different threshold changes the task.

05

Leakage

Time-based splitting and separate target files prevent future information from leaking into training.

06

Model drift

Reporting rules, variants, and surveillance coverage change over time; deployed performance would need monitoring.

Next steps

Turn a strong ranking model into a more trustworthy warning system.

  1. 01
    Fix the admissions normalization

    Correct the denominator behind admits_per100k and re-run evaluation + SHAP.

  2. 02
    Tune the XGBoost threshold

    Choose an operating point from the precision-recall curve based on the real cost of misses vs. false alarms.

  3. 03
    Address class imbalance

    Test scale_pos_weight or resampling to improve recall.

  4. 04
    Try regression + monitoring

    Predict next-week admissions directly and track performance by region and over time.

Main takeaway

Wastewater can contribute to an earlier COVID-19 surge warning — but only if we are equally serious about signal quality, threshold choice, and who the data represents.
